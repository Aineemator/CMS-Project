# CMS Project

This project is a content management system web application built with Node.js, Express, MongoDB, and plain HTML/CSS/JavaScript.

## Features
- User authentication and signup/login
- Task management dashboard
- Admin dashboard
- RESTful API routes

## Tech Stack
- Node.js
- Express.js
- MongoDB / Mongoose
- HTML, CSS, JavaScript

## Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```

## Environment Variables
Create a `.env` file and add your MongoDB connection string and JWT secret.

## Project Structure
- `server.js` - main server entry point
- `routes/` - API routes
- `controllers/` - request handlers
- `models/` - MongoDB schemas
- `public/` - frontend pages and assets
